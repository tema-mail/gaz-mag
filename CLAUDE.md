# Магазин газового оборудования (Болотное) – перенос gaz-mag.ru с Тильды на код

Сайт gaz-mag.ru (Тильда, проект 7680118, ИП Меньшиков А. Ю.) на Astro + Preact.
Замысел и границы – `docs/ЗАМЫСЕЛ.md`, решения – `docs/РЕШЕНИЯ.md`, долги – `docs/ТЕХДОЛГ.md`.

## Стек и запуск
- Astro 7 (статическая сборка), острова Preact, общее состояние – `@preact/signals` (`src/lib/store.ts`).
- `npm run dev` – разработка, `npm run build` – сборка в `dist/`.
- `npm run data` – заново снять товары, варианты и фильтры магазина (store.tildaapi.com) в `src/data/*.json`
  и картинки товаров в `public/img/p`. `npm run data -- --img` – скачать картинки страниц
  (ссылки `https://static.tildacdn.com/...` в `src/` → локальные через `src/lib/img.ts`).
- Публикация: пуш в main → GitHub Actions (`.github/workflows/deploy.yml`) → VPS Beget, gaz-mag.ru. Откат – workflow «Откат сайта». Приёмник заявок `server/lead.mjs` обновляется `DEPLOY_PUB=~/.config/gaz-mag/deploy_ed25519.pub zsh deploy/install.sh`.

## Структура
- `src/pages` – маршруты повторяют адреса оригинала (`/catalog_boilers`, `/<каталог>/tproduct/<id>-<slug>`, `/hubert`…).
- `src/components` – секции (.astro), `src/islands` – интерактив (корзина, избранное, фильтры, меню, формы, квиз).
- `src/data` – снятые данные; тексты страниц – в самих страницах.

## Соглашения
- Тире только короткое «–», длинное (U+2014) не ставить нигде.
- Каталог: на телефоне две карточки в ряд, с 1024px – три; фильтры – как на оригинале (марка, цена, характеристики),
  выбор прячет неподходящие товары. Скрытие через `hidden` страховать `[hidden]{display:none!important}`.
- Внутренние ссылки и картинки – только через `u()` из `src/lib/url.ts` (подпапка Pages задаётся `PUBLIC_BASE`).
- Факты (цены, сроки, скидки) – только с оригинала или от владельца. Не выдумывать.

## Правила работы
- Файл больше 800 строк не дописывать, а выносить новый модуль.
- Делать только то, о чём просили. После каждого рабочего шага – коммит.
- Чего не знаешь – спросить, а не подставить заглушку.
- После задачи – строка в `docs/РЕШЕНИЯ.md`, найденный долг – в `docs/ТЕХДОЛГ.md`.
